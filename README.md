A simple, modern, and responsive weather application built with HTML, CSS, and JavaScript.
This web app allows you to search for any city worldwide and displays real-time weather information including temperature, humidity, wind speed, weather description, and local time. Weather data is fetched from the OpenWeatherMap API.
